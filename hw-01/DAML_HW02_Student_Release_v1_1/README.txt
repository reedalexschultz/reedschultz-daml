DAML Homework 2 Student Release — v1.1

1. DAML_HW02_Python_Primer.ipynb is an optional, ungraded Python + NumPy warm-up. It takes about 15 minutes for students with some coding exposure and 20–25 minutes for complete beginners. It now includes basic Python data types, lists, dictionaries, conditionals, loops, functions, assertions, NumPy arrays, shapes, vectorization, and matrix multiplication.
2. DAML_HW02_Signal_Rescue.ipynb contains the required 30–45 minute assignment and optional bonus deep dive.

Complete cells marked YOUR CODE or YOUR RESPONSE. Keep function names and signatures unchanged. Before submission, restart the kernel/runtime and run all cells. Optional sections are skipped by default; set their RUN_BONUS flags to True only after completing them.

All display equations use Colab-compatible $$ ... $$ delimiters.
